itch.io (HTML5)

Für itch.io als HTML5 hochladen: Erstelle das ZIP mit bun run build:itch. Die ZIP enthält index.html im Root. Lade die Datei release/riftborn-web.zip als "shared files" hoch (Kind: HTML5, "This file will be played in the browser").

Zu GitHub Releases

Web (lokal starten)

Riftborn läuft im Browser via Vite. Benötigt Bun.

  • Installieren: bun install
  • Entwickeln: bun run dev → http://localhost:5173
  • Bauen: bun run build → dist/

Desktop (Electron)

Native Desktop-App für Windows, macOS, Linux.

  • Dev: bun run desktop
  • Prod (aus dist/): bun run desktop:prod
  • Portable EXE: bun run build:portable → release/

Co-op

Server starten und im Spiel mit P verbinden.

  • Beides gemeinsam: bun run dev:all (Client + WebSocket-Server)
  • Nur Server: bun run server
